Privacy policy

Your Minecraft data stays yours.

Effective 6 September 2026. This policy describes the Windows desktop application Hyperix Launcher and its official distribution pages.

What Hyperix stores locally

Hyperix stores launcher configuration, instance metadata, local game content, screenshots, logs, and account display metadata on the Windows device. Authentication credentials for Microsoft/Minecraft and supported account providers are kept separately using Windows user-scoped DPAPI. Hyperix does not store these credentials in its renderer data, ordinary account metadata files, screenshots, or launcher logs.

Services Hyperix connects to

When you choose to use a feature, Hyperix connects directly to the relevant service: Microsoft, Xbox and Minecraft services for Microsoft sign-in and Minecraft play; Mojang services for game metadata/assets; Modrinth and, where enabled, CurseForge for content discovery and downloads; and Ely.by only when you select that provider. Those services process data under their own policies.

Technical telemetry

A release sends technical telemetry only when it is built with a Hyperix collector endpoint and the Help improve Hyperix setting remains enabled. Current builds without such an endpoint send no telemetry. The allowlisted events are app start, Minecraft launch attempt, supervised game exit, and process-wait failure. They may contain the app version, operating-system/architecture, an ephemeral session identifier, bounded Minecraft version/loader, launch outcome and duration, and process exit status.

Telemetry never includes account names, authentication tokens/codes, instance IDs or names, server/world names, mod lists, filesystem paths, raw logs, screenshots, or play-time history. You can turn the setting off in Settings → Privacy; turning it off prevents future telemetry delivery.

What Hyperix does not do

Hyperix does not sell personal information, display advertising, run an in-app payment system, or re-host third-party mod files. It does not use local Minecraft worlds, mods, screenshots, or logs as technical telemetry.

Retention and control

Local launcher and game data remains on your device until you delete it through Hyperix, remove an account, uninstall/delete the Hyperix data directory, or remove the relevant game instance. The Storage Manager intentionally excludes worlds, mods, screenshots, accounts, and Minecraft runtime data from automatic cleanup.

Security and contact

We use platform credential protection, constrained native commands, provider allowlists, and verified downloads where provider hashes are supplied. No software can guarantee that third-party game content is safe. For support or privacy questions, use the Hyperix support page or email hyperix.contact@gmail.com. We will update this policy before materially changing data practices.
