Privacy

Support

Help us reproduce the issue safely.

Hyperix is maintained independently. Please include the launcher version, Windows version, relevant Minecraft version/loader, reproducible steps, and a sanitized error message.

General support

Use the official Hyperix issue tracker for a reproducible bug or feature request. Do not attach access tokens, refresh tokens, device codes, account credentials, private server addresses, worlds, or unredacted logs.

Security reports

For a security issue, do not publish credentials or a working exploit in a public issue. Contact hyperix.contact@gmail.com with a minimal reproduction and the affected Hyperix version. Before Store publication, this mailbox must remain monitored.

Content and rights reports

Hyperix does not host provider content. Report a mod, modpack, or creator-rights concern first through the relevant provider’s official reporting route. If Hyperix is displaying or handling that content incorrectly, include the provider project URL and an explanation in the issue tracker.

Official downloads

Only download Hyperix from this page, the official GitHub Releases page, or Microsoft Store after it is certified. Do not accept executables or account-login instructions from third parties.
