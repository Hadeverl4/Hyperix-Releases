Support

Help us reproduce the issue safely.

Hyperix is maintained independently. Please include your launcher version, Windows version, Minecraft version and loader, the steps to reproduce the problem, and the error message with private details removed.

General support

Use the official Hyperix issue tracker for a reproducible bug or feature request. Do not attach access tokens, refresh tokens, device codes, account credentials, private server addresses, worlds, or unredacted logs.

Security reports

If you find a security issue, please do not post credentials or a working exploit publicly. Email hyperix.contact@gmail.com with short steps to reproduce it and the affected Hyperix version.

Content and rights reports

Hyperix does not host provider content. Report a mod, modpack, or creator-rights concern first through the relevant provider’s official reporting route. If Hyperix is displaying or handling that content incorrectly, include the provider project URL and an explanation in the issue tracker.

Privacy requests

To ask what data Hyperix holds about you, or to correct or delete it, email hyperix.contact@gmail.com. The Privacy Policy explains what is collected.

Official downloads

Download Hyperix only from this page, the official GitHub Releases page or the official Microsoft Store. Do not accept executables or sign-in instructions from anyone else.
