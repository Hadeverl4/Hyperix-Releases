Why Hyperix

Built to respect
players and creators.

Official sources only

Hyperix uses official provider APIs for compatible Minecraft content discovery. It does not scrape provider websites, re-host files, bypass author restrictions, or present creator content as its own.

Creators decide

For CurseForge, a project is downloaded only where the creator has explicitly approved third-party distribution. Otherwise, Hyperix directs the player to the official project page.

Your account stays yours

Sign-in credentials are protected with Windows DPAPI on your PC and are never stored in plain text.

Free, no ads

The launcher is free to download and use, with no advertisements or bundled adware. Technical telemetry can be turned off in Settings. Privacy policy ↗

Questions

Good to know
before you download.

Is Hyperix free?

Yes. Hyperix is free to download and use, with no advertisements or bundled adware.

Which Minecraft does it run?

Minecraft: Java Edition, with Vanilla, Fabric, Quilt, Forge and NeoForge instances. Sign in with a Microsoft account that owns Java Edition. Ely.by accounts are also supported.

Microsoft Store or the direct installer?

Both install the same Hyperix app. The Microsoft Store handles installation and updates for you. The direct installer (.exe) may trigger a Windows SmartScreen notice for new releases, so verify the SHA-256 checksum shown in the download section.

Is my Microsoft account safe?

Sign-in tokens are encrypted with Windows DPAPI, tied to your Windows user account, and never stored in plain text. They stay out of the launcher interface, logs, telemetry and crash reports.

Where are my worlds and mods stored?

On your PC. Instances, worlds, mods, screenshots and settings stay local, and telemetry never includes world names, mod lists or file paths. You can turn telemetry off in Settings → Privacy. If you use Hyperix Connect, your Hyperix ID and friends list are stored online.

Can I play with friends?

Yes, from Hyperix 2.0. Sign in to Hyperix Connect, add friends, then open Play with friends to host your world or a managed Vanilla server and invite them. The feature is in Beta.

What do I need?

Windows 10 version 2004 or later, or Windows 11, on a 64-bit (x64) PC, plus an internet connection for sign-in and downloads. You don't need to install Java first: Hyperix downloads a verified Eclipse Temurin runtime when a game version needs it.
